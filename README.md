# Neotech Investment Platform

A secure investment platform for Guinea Conakry with a systematic, phased approach.

## Planning & Requirements

### Core Features
- User Registration
- KYC/AML Verification
- Wallet Integration
- Investment Dashboard

### Supported Products
- Micro-investments
- Savings Accounts
- Local Projects
- Crypto
- Forex

### Compliance
- Central Bank of Guinea
- APIP Regulations

### Tech Stack
- **Mobile:** React Native
- **Web:** React/Angular
- **Backend:** Node.js/Python
